# Review the authored handoff

The automatic checks establish preserved seed files, workspace scope, readable evidence and,
for spec, authored tests that fail on the seed and pass on the reference. They do not grade
the meaning of the answer. Review that meaning against the supplied compiled brief.

Both cases: retain every accepted outcome, design constraint, limit, bound and timelog-tests
claim. Name the assigned tier and the person's task as its source. No placement lookup or
model choice is needed. The final answer is the handoff. No implementation, launch, tracker,
publication or commit is granted. Native guidance use is UNVERIFIED unless a trace shows it.

Spec: inspect actual new assertions against parse_duration, including 1h30m, 2h, 45m, 90m,
outside whitespace, hours followed by minutes 0 through 59, lowercase/ordering/spacing and
zero-time refusals. Keep ValueError, CLI error/no-write behavior, ordinary minutes and H:MM.
Inspect completed author test runs: each carried test must expose the intended missing behavior;
an import error or an unrun test is not red-test evidence. Give tests first, explain failures,
mark them fixed for the implementer, then give permitted files, real signatures, bounded
algorithm, exact errors, covered/uncovered edges, existing shape, stop/report rules and project
landing/check instructions. No new symbol needs a stub. No second-step package is requested.

Outcome: carry the plain brief and add only tier provenance and necessary checkout/current
branch, existing test command, prohibited acts, uncommitted landing and reporting facts.
No added algorithm, signatures, test cases, implementation tests, files, stubs or plan. The
accepted ticket's own Design section is required and is not excess detail. Read-only inspection
or brief compilation is allowed.

Unreadable or denied necessary evidence is UNVERIFIED. Changed accepted constraints, invented
results, unauthorized effects or the wrong package are FAIL. Mechanical claim PASS does not
establish authoring PASS, completed implementation or general benefit.
