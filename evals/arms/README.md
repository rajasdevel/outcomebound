# Eval arms

`earlier-kernel.md` is the kernel of the `earlier` arm. It is an earlier wording of the
operating-contract block, kept as that arm installs it. Its `v=1.0.0` marker stays as it was
written.

It is not the current block. The current block is `templates/managed-block.agents.md.tmpl`, as
`outcomebound adopt` renders it. Do not edit `earlier-kernel.md` to match it, because the arm
measures the earlier wording. [evals/README.md](../README.md) describes each arm.
