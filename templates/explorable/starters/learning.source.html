This page teaches one idea: a cache answers a read so the database does not have to. You will guess first, then see the answer.

If you know this already, skip to the recall question.

A cache answers 9 of every 10 reads. 120 reads arrive each second. How many reads each second reach the database?
One read in ten misses the cache. 120 reads times one tenth is 12 reads each second.

What does the cache do on a miss?
On a miss the cache asks the database and keeps the answer, so the next read for it is a hit.
